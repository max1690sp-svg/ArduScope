# ASCOM Telescope Driver для Arduino Uno Equatorial Mount

Простой драйвер ASCOM для управления экваториальной монтировкой телескопа на базе Arduino Uno.

## Возможности
- Управление осями RA (прямое восхождение) и DEC (склонение)
- Гидирование (guiding) по всем четырем направлениям
- Перемещение с заданной скоростью
- Подключение через последовательный порт (USB)

## Требования
- Windows 10/11
- .NET Framework 4.7.2 или выше
- ASCOM Platform 6.x (скачать с https://ascom-standards.org/)
- Arduino Uno с загруженной прошивкой
- Visual Studio 2019/2022 (для компиляции)

## Установка и сборка

### Шаг 1: Установка ASCOM Platform
1. Скачайте ASCOM Platform 6 с официального сайта
2. Установите платформу

### Шаг 2: Загрузка прошивки на Arduino
1. Откройте `ArduinoFirmware/firmware.ino` в Arduino IDE
2. Выберите плату Arduino Uno и правильный COM порт
3. Нажмите "Upload"

### Шаг 3: Сборка драйвера
1. Откройте решение в Visual Studio
2. Убедитесь, что пути к ASCOM DLL верные (измените при необходимости в .csproj)
3. Скомпилируйте проект (Ctrl+Shift+B)
4. Зарегистрируйте DLL для COM Interop:
   ```
   regasm /codebase AscomArduinoMount.Telescope.dll
   ```

### Шаг 4: Использование
1. Подключите Arduino к компьютеру через USB
2. Запустите любое ASCOM-совместимое приложение (Stellarium, Cartes du Ciel, N.I.N.A.)
3. В настройках телескопа выберите "Arduino Equatorial Mount"
4. Настройте COM порт в диалоге настроек драйвера

## Протокол обмена
Драйвер общается с Arduino через последовательный порт используя простые текстовые команды:

### Команды:
| Команда | Описание | Пример |
|---------|----------|--------|
| `MOVE_RA <speed>` | Движение по оси RA (-1.0 до 1.0) | `MOVE_RA 0.5` |
| `MOVE_DEC <speed>` | Движение по оси DEC (-1.0 до 1.0) | `MOVE_DEC -0.3` |
| `STOP` | Остановить все движения | `STOP` |
| `GUIDE <dir> <ms>` | Гидирование (N, S, E, W) | `GUIDE N 1000` |
| `STATUS` | Получить текущий статус | `STATUS` |
| `HOME` | Переход в домашнюю позицию | `HOME` |

### Ответы Arduino:
- `OK` - Команда выполнена успешно
- `ERROR` - Ошибка выполнения
- `STATUS:RA=<value>,DEC=<value>` - Текущие координаты (RA в часах, DEC в градусах)

## Аппаратная часть
Смотрите подробную схему подключения в файле `ArduinoFirmware/WIRING.md`

### Краткая схема:
- **Ось RA**: Pins 2 (STEP), 3 (DIR), 4 (ENABLE)
- **Ось DEC**: Pins 5 (STEP), 6 (DIR), 7 (ENABLE)
- Драйверы: A4988 или DRV8825
- Двигатели: NEMA 17 шаговые двигатели

## Настройка параметров
В файле `firmware.ino` можно изменить:
- `STEPS_PER_REVOLUTION` - количество шагов двигателя на оборот
- `MICROSTEPS` - режим микроступеней драйвера
- `RA_GEAR_RATIO`, `DEC_GEAR_RATIO` - передаточные числа редукторов

## Troubleshooting

### Драйвер не появляется в списке ASCOM
- Убедитесь, что DLL собран с флагом `/codebase`
- Проверьте регистрацию через `regasm /list | find "Arduino"`

### Нет связи с Arduino
- Проверьте правильный COM порт в настройках
- Убедитесь, что прошивка загружена корректно
- Проверьте скорость baud rate (должна быть 9600)

### Двигатели не вращаются
- Проверьте питание драйверов
- Настройте ток на потенциометре драйвера
- Проверьте правильность подключения обмоток двигателя
