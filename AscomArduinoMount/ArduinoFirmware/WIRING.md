# Схема подключения Arduino Uno к экваториальной монтировке

## Необходимые компоненты

1. **Arduino Uno**
2. **2 шаговых двигателя** (NEMA 17 или аналогичные)
3. **2 драйвера шаговых двигателей** (A4988 или DRV8825)
4. **Блок питания** (12V для двигателей, 5V для Arduino)
5. **Конденсаторы** (100µF для каждого драйвера)
6. **Радиаторы** для драйверов (опционально, но рекомендуется)

## Схема подключения

### Драйвер оси RA (прямое восхождение)

```
Arduino Uno    ->    A4988/DRV8825
-----------         -------------
Pin 2 (STEP)   ->   STEP
Pin 3 (DIR)    ->   DIR
Pin 4 (ENABLE) ->   ENABLE
GND            ->   GND
5V             ->   VDD (логическое питание)

Двигатель RA:
A+ -> 1A
A- -> 1B
B+ -> 2A
B- -> 2B

Питание драйвера:
VMOT -> 12V (от внешнего БП)
GND  -> GND (общий с Arduino)
```

### Драйвер оси DEC (склонение)

```
Arduino Uno    ->    A4988/DRV8825
-----------         -------------
Pin 5 (STEP)   ->   STEP
Pin 6 (DIR)    ->   DIR
Pin 7 (ENABLE) ->   ENABLE
GND            ->   GND
5V             ->   VDD (логическое питание)

Двигатель DEC:
A+ -> 1A
A- -> 1B
B+ -> 2A
B- -> 2B

Питание драйвера:
VMOT -> 12V (от внешнего БП)
GND  -> GND (общий с Arduino)
```

### Настройка микроступеней (A4988)

Для микроступеней 1/16 (рекомендуется):
```
MS1 -> HIGH (5V)
MS2 -> HIGH (5V)
MS3 -> HIGH (5V)
```

### Важные замечания

1. **Общий земляной провод**: Обязательно соедините GND Arduino с GND блока питания двигателей
2. **Конденсаторы**: Установите электролитический конденсатор 100µF между VMOT и GND рядом с каждым драйвером
3. **Ток двигателей**: Настройте ток на драйверах с помощью потенциометра (не превышайте номинальный ток двигателей)
4. **Охлаждение**: При длительной работе установите радиаторы на драйверы

## Альтернативная плата управления

Для более надежной работы рассмотрите использование специализированных плат:
- **Arduino CNC Shield v3** - готовая плата с разъемами для драйверов
- **RAMPS 1.4** - плата для 3D принтеров, адаптируемая для телескопов
- **SKR Mini** - современная плата с тихими драйверами TMC2208/TMC2209

## Подключение к компьютеру

Подключите Arduino Uno к компьютеру через USB кабель. Система определит его как COM порт (Windows) или /dev/ttyUSB* (Linux).

## Безопасность

- Отключайте питание перед изменением подключений
- Не прикасайтесь к металлическим частям при включенном питании
- Используйте предохранитель в цепи питания двигателей
